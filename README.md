JDBC Student Record System

Description

This is a simple Java JDBC project that connects to a MySQL database and performs basic operations.

Features

-Add student
-View all students
-Remove Student
-Technologies Used

1.Java
2.JDBC
3.MySQL

Setup

-Clone the repository
-Create a MySQL database named "students_database"
-Create a table:
-CREATE TABLE students ( id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(100), age INT, course VARCHAR(100) );

-Update database credentials in "dbconnection.java"
-Run the program
Notes

Database credentials are not included for security reasons.
